# DeucaClicker
A hyper-fast, low-latency Win32 Auto-Clicker written in native C++20 and Dear ImGui. Uses kernel-level input injection for maximum performance. ( Un auto-clic Win32 ultra-rapide et à faible latence, écrit en C++20 natif et utilisant Dear ImGui. Utilise l'injection d'entrée au niveau du noyau pour des performances optimales.)
